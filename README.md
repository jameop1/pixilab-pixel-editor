# PIXILAB — Pixel Art & Animation Studio

A full-featured in-browser pixel art editor and sprite animator built with modern soft-neubrutalist aesthetics.

## Features

- **Drawing Tools**: Pen, eraser, paint bucket fill, line, rectangle, ellipse, color picker, and dithering brushes.
- **Layers & Blending**: Multi-layer support with visibility toggles, opacity control, and reordering.
- **Animation Timeline**: Frame-by-frame sprite animator with adjustable FPS, onion skinning, and loop playback preview.
- **Palette Presets**: Classic retro hardware palettes (Game Boy, Pico-8, NES, Commodore 64) plus custom palette import/export.
- **Flexible Export**: Export sprites as animated GIFs, sprite sheets, or lossless scaled PNGs.

## Getting Started

Open `index.html` in any modern web browser.
